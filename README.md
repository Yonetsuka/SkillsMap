# 📘 SkillTracker
### Aplicativo para mapear competências e acompanhar progresso usando AsyncStorage

---

## 🧠 Sobre o projeto

w
---

## 🚀 Funcionalidades

- Adicionar novas competências  
- Atualizar progresso percentual  
- Listar todas as competências  
- Remover habilidades  
- Salvamento persistente com **AsyncStorage**

---

## 🛠️ Tecnologias utilizadas

- React Native  
- Expo  
- TypeScript  
- Async-storage  

## ⚙️ Configuração do ambiente

### 1. Instalar Node.js  
https://nodejs.org

### 2. Instalar o Expo CLI  

npm install -g expo-cli

### 3. Instalar dependências
npm install 

### 4. Iniciar o servidor
npm start
